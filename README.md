### 🧪 Some Projects I Have Built
- **[Friends on Campus (FoC)](https://github.com/AY2627S1-CS3219-P22/FoC):** A peer-to-peer campus errand platform where students request items and other students deliver them, running on a closed credit economy. Built as microservices with Express.js, gRPC, RabbitMQ and Redis, and deployed on Kubernetes (AWS EKS) with per-service CI/CD. I worked on the supplier service, the async messaging topology and transactional outbox, and CI/CD, and contributed to the OTP flow, password hashing and caching.
- **[Terrain Mapper (NASA Space Apps)](https://github.com/sunpterodactyl/SunpterodactylNasaChallenge):** A tool that ranks Earth terrain patches by how closely their 3D shape matches a chosen Moon site, so researchers can find analogue test sites. Built with FastAPI, React and three.js on Copernicus and LOLA elevation data, with a fidelity score validated against baselines. [Live demo](https://sunpterodactyl-nasa-challenge.vercel.app/)
